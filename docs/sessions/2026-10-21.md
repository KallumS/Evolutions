# 2026-10-21 - the first version

## Asked

"A JSFX that creates similar movements/motions to Olafur Arnalds Cells by
Spitfire Audio or Time Macro/Micro by Orchestral Tools using only midi. When
keys are pressed down on a keyboard the midi evolves in real time for the
duration that the keys are held down. There should be a recorder which
allows you to drag the midi out into Reaper. The evolution should be
different each time and evolve slower or faster based on chosen settings."
Follow the house style (Good Idea's HIG review and COLOUR doc were
attached, with the JSFX reference and the API page); use what helps from
Miderator, Good Idea, Midi Variator, Midi Suggester, Starting Blocks, Midi
Catalogue, ScaleView for REAPER and AutoCC. Then: "the most useful repo will
either be Miderator or Midi Variator", and the Educational Materials zip.

## What was read

All eight repos were cloned read-only. **AutoCC** turned out to matter most
for the code - the family's one JSFX, whose window framework, ysfx checker
and notes on the language were carried over. **Midi Variator** gave the
musical habits: seeded Park-Miller dice with a stream per part, the clash
guard, feel in milliseconds and velocity steps. **Miderator** is a JUCE Mac
app whose generators are the Lua engines; its use here was its rules for
working (verify by rendering, commit early). Good Idea gave the `.mid`
writer, the export folder, "an idea is a number", and the shape of the docs.
The Educational Materials are the same zip Good Idea read in full
(`docs/READING.md` there); Hutchinson's minimalism chapter was read again at
the source.

## The route

1. The fork every repo in the family has met: JSFX or ReaScript. Both
   (decision 0001): only a JSFX hears held keys live, and only a script can
   write a file or add an item. The drag became the Media Explorer's.
2. The engine, in EEL2: the held keys as a ladder (0002), five layers as
   Belkin's planes coming in in order (0003), one energy over a pace with
   Reich's phasing and Glass's additive process in the arpeggio (0004),
   colour tones by the clash guard (0005), a variation number (0006), the
   take (0007).
3. `tools/host.cpp`: AutoCC's ysfx host, which threw away the MIDI, now
   keeps it and takes a tempo and a transport. `tools/enginecheck.py` on
   top: 77 checks of what is played.
4. The helper (`me_midi`, `me_place`, the script) against a mock written
   from the API page: 89 checks.
5. The window: AutoCC's framework, its checker ported (198 checks), the
   screenshots looked at.
6. Every rule broken on purpose (`tools/bite.py`): 24 breaks, all caught in
   the end (below).

## What broke, and what looked broken and wasn't

- **The first hold hung the host.** `next_grid(t + 0.0001, g)` returns `t`
  itself for a grid of a beat or more; a step repeated forever. Now 0.01.
- **`pkill -f tools/build/host` killed its own shell** (the name was in the
  command line), and with it the edit in the same command - the fix above
  seemed not to work until that was seen. Miderator's CLAUDE.md warns of
  exactly this.
- **`1e12` is not EEL2.** Compile error; now spelt out, and checked for.
- **Notes stuck at the end of a hold.** A note pushed a few milliseconds late
  by Feel was scheduled after the release that ended it; the sort then put
  its note-off before its note-on. `an_end` now never ends a note before its
  start plus two samples.
- **The pad left out the third**: C3 G3 C4 for C major. It now voices every
  chord tone first (C3 G3 E4), and with too few voices leaves out the fifth
  (Dm7: D3 C4 F4).
- **Your own keys cut by generated notes** when Held Keys is Played on the
  same channel: they are now notes like any other, so the re-strike rule
  keeps them.
- **The take missed a hold's last note-offs**: it ended before the block that
  sent them. It now ends after.
- **Only the Bass row was drawn.** EEL2's names are case-insensitive: `nl`
  (a row's line count) was `NL` (the number of layers). Renamed, and the
  checker now fails on any two names differing only in case.
- **Text cut short at 150%** in the layer rows: they wrap now.
- Looked broken, wasn't: "the message bar cuts the helper's name in half" -
  the checker's logger kept 60 bytes of each string and split a curly quote.
  It keeps 140 now. And the host's `cc`/`note` without a channel sent on
  channel 16 (a C++ failed read sets 0); fixed in the host.
- Two bites were **missed** at first - a short note cutting the pad's held
  note on a shared channel, and REAPER's grid after a hold made while
  stopped: the code was right but nothing tested it. Both have tests now,
  and both bite.

## Deviations from the family, on purpose

- The window's ground is the house `#23272E` (COLOUR.md); AutoCC's is darker.
- Note names in the window are spelt C#, Eb (ScaleView's spelling), not ♯ ♭:
  REAPER's fallback Arial may not have them (AutoCC's reason for writing
  "Command" rather than ⌘).
