# 2026-10-31 - a note sorted before its own start

## Asked

From Middaw (which runs this JSFX natively): one of the engine check's
"nothing hanging" checks failed about one run in six. "Yes please" to
fixing it here.

## Done

- Found it with a locked variation, which plays the same notes in any host:
  a note struck in a block's last sample and ended in the same block had its
  note-off clamped onto its note-on's offset, sorted first, and sounded
  until the next chord. `an_end` now takes the note-on back (`q_unsend`)
  in that case. Decision 0009.
- `tools/enginecheck.py`: sixty locked variations through a chord change,
  nothing left hanging. Fails on the old file (5 of 120 runs), passes now:
  78 of 78.

## Not done

  `tools/test.sh` before publishing.
